# Лабораторная работа №1
## Задание:
Написать программу на языке C/C++ для перемножения двух квадратных матриц. Исходные данные: файл или файлы со значениями исходных матриц. Выходные данные: файл со значениями результирующей матрицы, время выполнения, объём задачи и другое. Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО, например на Matlab или Python.

## Описание:
Программа на C++ для перемножения двух квадратных матриц **N × N** классическим методом (тройной вложенный цикл). 
Входные данные читаются из текстовых файлов, результат записывается в файл, замеряется время выполнения.
Корректность результата проверяется автоматически с помощью библиотеки **NumPy**.

## Проект:

| Файл                     | Назначение                                    |
|--------------------------|-----------------------------------------------|
| `matrix_multiplier.cpp`  | Перемножение матриц                           |
| `generate_matrices.py`   | Генерация двух случайных матриц `N x N`       |
| `build_plot.py`          | Построение графика                            |

| `CMakeLists.txt`         | Конфигурация сборки CMake                     |
| `matrix1.txt`            | Первая входная матрица (генерируется)         |

| `result.txt`             | Результат перемножения                        |
| `timings.txt`            | Результаты замеров времени                    |
| `graph.png`              | Итоговый график                               |

## Верификация результата

Запуск:
```bash
python verify.py
```

Скрипт сравнивает `result.txt` с эталонным результатом, полученным через
`numpy.dot(A, B)`, и выводит:
```
Верификация пройдена: результаты C++ и NumPy совпадают.
```
либо сообщает о расхождениях.
